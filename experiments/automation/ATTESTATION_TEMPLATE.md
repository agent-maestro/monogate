# Attestation template — truth-or-named-gap

For the class of controls **no gate can reach**: contamination, arm-labelling, session logging,
isolation of authorship. These rest on conduct, and conduct can only be made *accountable*, never
*verified*. This template is the strongest available construction for that.

## The one rule

> **A line that cannot be stated truthfully must SAY SO, in the line, rather than be omitted.**

This is UNAVAILABLE-is-failure extended to human testimony. A form where every field demands
truth-or-named-gap makes silent omission **structurally impossible**: there is no way to leave a
question unanswered that looks like an answer. An attestation with a gap named is evidence; an
attestation with a gap hidden is worse than none, because it converts an unknown into a false
assurance — which is the failure this whole programme exists to detect.

## Form

```
attestation for : <what is being attested — the trap set, the arm label, the session log>
date            : <YYYY-MM-DD>
attested by     : <who — a person, or a model plus version>

<field>         : <statement>  |  CANNOT STATE: <why>
...

signed          : <orchestrator>
```

Every field takes one of two shapes and no third:

* a **statement** — specific enough to be checked by someone who doubts it; or
* `CANNOT STATE: <reason>` — which is a valid, expected, non-shameful answer.

"N/A", a blank, and a removed line are **not** valid answers. If a field does not apply, that is
itself a statement: `CANNOT STATE: field does not apply because …`.

## Who this binds

**Everyone the project asks for an attestation, including the AI.** An attestation regime that exempts
its author is the same defect as a constitution that binds only the junior party — and this project has
now recorded the rule set overriding both principals, so the exemption would be conspicuous.

## Known limit, stated because this template is about limits

It does not make the attested fact **true**. It makes the claim **specific, dated, attributed, and
gap-explicit** — which is what turns "we were careful" into something a reader can weigh, and a later
discrepancy into something a reader can find.
